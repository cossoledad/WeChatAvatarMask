# 技术说明

- **定位**：OpenCV 背景估计、连通区域、右侧头像列和边缘梯度精修；无需原头像。可选 `source` 参数保留模板匹配兼容模式。
- **合成**：每张图统一圆角；水平跨度及纵向采样计算覆盖率，局部背景重建减少旧头像残留。部分遮挡使用可见高度裁切。输出 PNG，不保留输入 EXIF。
- **前端**：原生 ES modules，双指/滚轮缩放及拖动；批量保存直接下载每张 PNG，支持目录选择的浏览器可直接保存到文件夹。
- **存储**：SQLite WAL 保存头像、最后选择、任务原图及微调参数；头像按内容去重。内存缓存有数量、容量和空闲时间限制，淘汰后可从磁盘恢复。任务清空不删除头像库。
- **部署**：FastAPI 同端口提供页面和 API；单 worker、普通服务账号、只读代码、独立可写数据目录。GitHub 原生 ARM runner 打包依赖，更新采用 SHA256 校验、独立 venv 和版本链接切换。

主要接口：`/api/avatars` 管理头像库，`/api/avatars/{id}/select` 选择默认头像；`POST /api/sessions` 批量上传，`GET /api/sessions/{id}` 恢复任务，`POST …/images/{id}/render` 保存参数并返回 PNG，`DELETE /api/sessions/{id}` 清空任务。

检测针对微信式布局，复杂背景、严重遮挡和 JPEG 边缘仍需人工检查。后续优先积累原始 PNG 及独立标注，再评估训练模型。当前不包含公网认证、用户隔离或自动数据清理。
