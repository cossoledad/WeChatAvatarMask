# 头像隐私 · 手机优先的聊天截图替换工具

批量选择聊天截图后自动替换**右侧自己的头像**。无需上传原头像，默认使用内置小熊图片；点击右上角头像可上传自己的替换图片，也会直接应用到当前批次。同一张截图内全部头像使用同一个圆角半径，不同截图分别估计。左侧头像、正文、昵称、聊天图片及内嵌小图保持原样。

Python / OpenCV / FastAPI 后端与独立 Node.js 前端分离，图片在本机处理，无账号、云端模型或外部字体。首页只有截图选择入口；结果只显示处理后的图片，详情仅保留圆角与保存。

## 启动

```powershell
.\start.ps1
# 新机器安装依赖：
.\start.ps1 -Install
```

打开 **http://127.0.0.1:5178**。要求 Python 3.12–3.14、Node.js 20+。本机项目 `.venv` 已安装依赖；启动脚本会寻找已安装的有效 Node，避免系统别名和版本管理器未配置造成启动失败。窗口保持打开，Ctrl+C 停止服务。8000 / 5178 已占用时不会结束其他进程。

从真实手机测试，电脑与手机连接同一 Wi-Fi，然后在停止已有服务后运行：

```powershell
.\start.ps1 -Lan
```

使用脚本打印的 `http://电脑局域网IP:5178`。此选项只将前端开放到本地网络，后端仍监听 127.0.0.1，通过同源代理处理图片。只在可信网络使用；不是包含身份验证的公网部署方案。不会自动修改 Windows 防火墙。本机测试集入口仅能从电脑访问，局域网访问被代理拒绝。

分别启动也可以：

```powershell
.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
# 另一窗口：
node frontend/server.mjs
```

前端是原生 ES modules，无需 npm install 或构建。接口文档：**http://127.0.0.1:8000/docs**。

## 手机使用流程

1. 点击“选择截图”，批量选择 1–30 张图片，自动处理。
2. 结果仅显示处理后的图片，点击“保存”或“保存全部”。单张保存 PNG，多张下载 ZIP，内含 PNG 和替换记录。
3. 轻点图片进入详情。双指捏合或鼠标滚轮缩放，以手势中心或鼠标位置为中心；单指或鼠标拖动平移，无放大按钮。仅图片区域捕获手势，页面其他区域保持常规滚动。
4. “圆角”滑块以 0.1 px 步进调整该图全部头像；更新结果保留当前缩放和平移位置。详情不显示原图、头像框、坐标或补选入口。

缩放范围从完整显示图片到至少原图的 200%；不会缩小到看不见或拖出视野。窗口方向变化会保留相对放大倍数；键盘聚焦图片后支持 `+` / `-`、方向键和 `0` 复位，作为不显示额外按钮的辅助操作。提示文字仅在处理失败或未识别到头像时出现。

替换头像内置于 `backend/assets/default-avatar.jpg`，不依赖测试数据目录存在。图片居中裁切、等比缩放填充头像框。EXIF 方向在读取时应用，PNG 不保留原图 EXIF；透明输入铺白底。

支持 JPEG / PNG / WebP，单文件不超过 15 MB、1600 万像素；单批解码总量约 220 MB，任务缓存总量约 440 MB。任务在进程内存中保留 30 分钟，超期后下一次请求清理；重新选择会释放前一任务。上传期间框架可能使用系统临时文件，请求结束后关闭。清除任务不等于安全擦除内存、浏览器缓存或已下载结果。

## 无原头像检测与圆角

默认流程从截图估计界面背景，通过前景连通区域寻找右侧近方形头像，再结合共同的列位置、尺寸和逐行占用，恢复部分被底边或输入栏遮住的头像。使用直边梯度修正框位置，无需比较人脸或任何预设原头像。它是针对微信式聊天布局的视觉规则，不是人脸身份识别。

圆角使用角区背景和前景对比估计，再将可靠完整头像的半径取稳健中值，作为该张截图的统一半径。合成时水平跨度精确计算，纵向 32 次采样求像素覆盖，减少原 4×4 二值采样造成的透明度台阶。四角从头像外采样并插值得到局部背景，避免与旧头像颜色混合形成残留；只修改掩膜覆盖像素。检测保留独立的宽高边界，不再强行平均为正方形；部分可见头像使用 `clip_h` 保护输入栏。

API 仍兼容可选 `source` / `replacement` 参数，提供原版模板匹配方式供开发测试；当前极简界面不需要这些输入。核心端点：

| 请求 | 行为 |
| --- | --- |
| `POST /api/sessions` | 只提交多个 `screenshots` 即可自动处理右侧头像 |
| `POST /api/sessions/{sid}/replacement` | 上传 `replacement`，更换当前批次的目标头像，不重新检测 |
| `GET /api/default-avatar` | 内置替换头像 |
| `GET /api/sessions/{sid}/images/{iid}/thumbnail` | 替换后的预览缩略图 |
| `POST /api/sessions/{sid}/images/{iid}/render` | `boxes` 与整图 `radius`，返回 PNG |
| `POST /api/sessions/{sid}/export` | `edits` 与整图 `radii`，输出 ZIP |
| `DELETE /api/sessions/{sid}` | 释放任务 |

技术细节与训练路线见 [技术方案](docs/TECHNICAL_DESIGN.md)。

## 验证

```powershell
.venv\Scripts\python.exe -m pytest -q
node --test frontend/image-viewer.test.mjs
.venv\Scripts\python.exe scripts/evaluate.py
# 可选：原版模板模式对照
.venv\Scripts\python.exe scripts/evaluate.py --template
```

13 项 Python 测试覆盖互不相同且未出现在项目素材中的头像、深浅背景、仅右侧检测、部分可见头像、只上传截图的接口、默认头像，以及整图统一半径在导出端的强制执行。6 项前端交互测试覆盖鼠标焦点稳定、双指中心移动、缩放边界、屏幕旋转、滚轮事件与双指转单指拖动及取消。

此前 23 张真实截图的默认流程返回 **64 处右侧头像候选**，包含 **3 处截断头像**，掩膜外改变像素数 **0**，当时批处理约 **13.39 秒**。本次头像上传与像素边缘优化按用户要求仅做必要检查，未重跑全量样本；以上保留为历史基线。旧模板模式额外的 2 处位于聊天内嵌小图中，不属于新默认范围。没有独立逐像素人工真值，不能据此承诺零漏检或完美边缘。

结果保存在 `artifacts/evaluation-right/`，包含替换 PNG、检测框、边缘对照和 `report.json`，压缩包为 `artifacts/avatar-mask-right-results.zip`。原输入和旧结果不会被覆盖；测试图片和输出均被 Git 忽略。

## 适用范围

当前自动检测面向右侧头像列清晰、背景较平坦的微信式截图，支持照片、插画和不同头像内容。复杂壁纸、其他社交软件布局、头像几乎为空白、严重遮挡、旋转或拼接截图可能漏检或误检；当前极简界面不提供人工改框。没有可靠头像种子时不会猜测任意右侧图像。

JPEG 的压缩和重采样使原始边界不唯一，圆角估计仍需查看实际效果。原始 PNG 和独立标注将有助于进一步提升定位与边缘精度。用户必须在分享前检查；昵称、文字及其他聊天图片不在替换范围。
