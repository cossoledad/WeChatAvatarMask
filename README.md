# 微信头像替换

批量上传聊天截图，自动替换右侧自己的头像，无需原头像。点击右上角选择或上传替换头像；最后使用的头像自动成为默认。结果支持手势缩放、整图统一圆角微调和逐张 PNG 下载。

图片在本机处理。头像库、默认选择和任务缓存持久保存，重启和更新保留；“清空”仅删除当前任务。刷新页面可恢复同一标签页的任务。多图下载时，浏览器可能要求允许下载多个文件。

Windows 开发：Python 3.12–3.14、Node.js 20+。

```powershell
.\start.ps1 -Install
# 同一 Wi-Fi 下手机访问：
.\start.ps1 -Lan
```

打开脚本显示的地址，Ctrl+C 停止。开发数据位于 `data/`，已从 Git 和发布包排除。

ARM Ubuntu 24.04 使用 Python 单服务，默认端口 **30127**，不需要 Nginx 或 Node.js。安装、GitHub 发布及更新见 [部署说明](docs/DEPLOYMENT_ARM_UBUNTU.md)。

检测面向背景较平坦的微信聊天截图；复杂壁纸、遮挡等可能误检或漏检，分享前请检查。昵称、文字和左侧头像不处理。[技术说明](docs/TECHNICAL_DESIGN.md)
